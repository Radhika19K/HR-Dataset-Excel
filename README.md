# HR Dataset Analysis (Excel)

## Project Overview
This project analyzes an HR dataset using Microsoft Excel to identify employee trends and generate business insights through data cleaning, pivot tables, charts, and dashboards.

## Objectives
- Analyze employee demographics
- Study attrition trends
- Compare salaries and job roles
- Evaluate employee performance
- Create an interactive HR dashboard

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Dataset
- File: HR Dataset.xlsx
- Contains employee information such as age, gender, department, salary, job role, education, and attrition.

## Key Insights
- Attrition trends by department
- Salary distribution
- Gender-wise employee count
- Department-wise workforce analysis
- Employee performance overview
